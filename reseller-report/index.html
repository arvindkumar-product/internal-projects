How these numbers are derived (read before using this in a review): Leads Attempted / Qualified / Appointments / dealer & rooftop rows are carried over verbatim from reference-docs/prototypes/vini-reseller-reports-prototype.html (already internally consistent — weekly buckets sum to the KPI totals). Call Answered, Total Calls, Total SMS, Transfer, Callback, Call Answer Rate (Inbound) and Total Accounts, Conversation Rate (Outbound) are new fields layered on top for this ask; they're plausible extrapolations from the same ratios, not real telemetry. None of this is in reference-docs/prds/partner-console-v2-api-prd.md §15.8–15.13 today — that spec only covers calls/leads/appointments/avg-duration. Before building this for real, flag the new fields (Total SMS, Transfer, Callback, Call Answer Rate, Total Accounts, Conversation Rate) to backend to confirm whether Vini's call data actually captures them.
