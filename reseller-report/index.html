Only the larger record is shown and counted in the dealer/portfolio totals; the smaller one is suppressed pending Spyne Ops de-duplication at the source.

Click a Dream Automotive rooftop + agent row above to expand a day-wise breakdown (hierarchy: Dealer → Rooftop + Agent → Date), fixed to the last 30 days. Daily figures are synthetic — each row's known period total is split across those 30 days with a seeded distribution rather than real day-by-day telemetry, so re-opening a row gives the same numbers back every time. Every other dealer only has period totals today — no rooftop × agent-type breakdown to drill into — so this level isn't available for them yet.
